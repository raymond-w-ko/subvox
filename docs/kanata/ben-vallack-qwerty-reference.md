# Ben Vallack's layout, in QWERTY

**Reference date: approximately September 2026.** [Original layout in Oryx](https://configure.zsa.io/voyager/layouts/9WygO/latest/0).

Ben uses Graphite; this reference presents the layout as QWERTY. Based on the seven supplied screenshots.

## 0 — Main

Tap letters normally. Hold these keys for modifiers or layers:

| Key | Hold action |
| --- | --- |
| S | Left Ctrl |
| D | Left Alt |
| F | Left Win |
| J | Right Win |
| K | Right Alt |
| L | Right Ctrl |
| V or M | Shortcut (1) |
| C or , | Sym A (2) |
| X or . | Sym B (3) |
| Z or / | Numbers (4) |
| Y | Mouse (6) |

**Thumbs:** left = Space, hold for Meh (Ctrl + Alt + Shift); right = Right Shift.

Two extra keys on the right edge type `;` (top row) and `,` (home row).
